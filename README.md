# Mini Campus Marketplace

## 📌 About the Project

Mini Campus Marketplace is a small collaborative web application created as a practice project for our student software development team.

The purpose of this project is to give team members practical experience in software development, Git, GitHub, frontend development, backend development, database management, testing, and teamwork before we begin developing the larger TTU Marketplace system.

## 🎯 Objectives

- Practice collaborative software development
- Learn Git and GitHub workflows
- Practice working with branches and pull requests
- Improve programming skills
- Practice frontend development
- Practice backend development
- Practice database design
- Learn software testing and debugging
- Understand how different parts of a software system communicate

## 🚀 Main Features

### Users
- View products
- Search products
- View product details

### Sellers
- Add products
- Edit products
- Delete products

### Products
- Product name
- Price
- Category
- Description
- Seller
- Product image

### Cart
- Add products to cart
- Remove products from cart
- View cart total
